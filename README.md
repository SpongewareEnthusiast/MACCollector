## Why?
When working as a desktop support, I had to collect MAC addresses of (yet) unnetworked devices, which were often on a tiny QR sticket in hard to reach places.
## What?
A simple mobile app using the QR Scanner api that saved the list for devices for a given session (room, floor etc) to the filesystem as CSV file. The CSV file would later get emailed. 
## Impact
A tool highly relevant to the simple worklow of deplying equipment in a very big complex, saved me loads of time and massively reduced error rates when adding the devices to the network.
